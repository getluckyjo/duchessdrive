# Google Docs are not being exported for tania@ and drinkdope.com

## What happens

Drive copies for `tania@theduchess.co.za` and the `drinkdope.com` accounts
complete, but every Google-native file (Docs, Sheets, Slides) fails:

    ERROR : <file>.docx: Failed to copy: failed to open source object:
            open file failed: googleapi: got HTTP response code 403
            with body: ... <title>Access Denied</title>

Binary files (PDF, JPG, XLSX uploaded as XLSX, video) copy perfectly. Only the
Google-native ones that have to go through Drive's *export* endpoint fail.

Counts so far: **1,654 files for tania@**, 37 across the drinkdope.com accounts.

## It is not permissions, and not rclone

For one of the failing files, owned by the impersonated user themselves:

    owners:       andrew@drinkdope.com     <- his own file
    shared:       false
    canDownload:  true
    canCopy:      true
    copyRequiresWriterPermission: false

...and `files.export` still returns 403. Retrying does not help, and it fails
for every export format (docx, and plain text too).

## It is per-account

Same service account, same `drive.readonly` scope, same API call, one document
owned by each user:

| account                     | files.export |
|-----------------------------|--------------|
| johannes@theduchess.co.za   | OK (428 KB)  |
| inus@theduchess.co.za       | OK (220 KB)  |
| tania@theduchess.co.za      | **403**      |
| andrew@drinkdope.com        | **403**      |

The two that work are the two known to hold a full Workspace licence. The two
that fail are the ones licensed later, during the cancelled-subscription
cleanup.

## Most likely cause

tania@ and the drinkdope.com users are on the **Archived User** SKU (or an OU
with Drive and Docs switched off) rather than a full Business Standard licence.
Archived User is retention-only: metadata reads and raw file downloads still
work, which is exactly the behaviour above, but the Docs service is not
provisioned, so the export endpoint refuses.

## Fix

1. Admin console -> Billing -> Subscriptions: check which SKU is assigned to
   `tania@theduchess.co.za` and each `drinkdope.com` user. Compare against
   `johannes@theduchess.co.za`, which works.
2. Assign the same full licence those two have.
3. Also confirm Apps -> Google Workspace -> Drive and Docs is ON for their OU.
4. Re-run the Drive copy for those accounts. rclone re-fetches only what is
   missing, so it will pick up the 1,654 documents and nothing else.

Until that is done, those 1,691 documents are the only known gap in the backup.
`./scripts/08-export-blocked.sh` regenerates the full list into
`inventory/export-blocked.tsv`.
